# 🚇 부산 지하철 이용객 수 지도 분석 앱

파이썬(Python)과 스트림릿(Streamlit)을 활용하여 부산 지하철 역별 이용객 수를 지도에 시각화하는 데이터 분석 웹 애플리케이션입니다.

## 📌 주요 기능
* **CSV 데이터 업로드**: `busan_subway.csv` 파일을 업로드하여 데이터를 불러옵니다.
* **호선별 필터링**: 다중 선택(Multiselect) 기능을 통해 원하는 호선(1~4호선 등)의 데이터만 걸러서 볼 수 있습니다.
* **상위 5개 역 추출**: 선택한 호선 내에서 이용객 수가 가장 많은 상위 5개 역을 표(Table) 형태로 제공합니다.
* **지도 시각화 (Folium)**: 
  * 이용객 수에 비례하여 마커(원)의 크기가 다르게 표시됩니다.
  * 호선별로 마커의 색상이 다르게 적용되어 직관적으로 구분할 수 있습니다.
  * 마커에 마우스를 올리면 '역명'이, 클릭하면 '이용객 수'가 나타납니다.

## 🛠️ 사용된 기술
* **Language**: Python
* **Library**: Streamlit, Pandas, Folium, Streamlit-Folium

## 🚀 실행 방법

1. 이 저장소(Repository)를 클론하거나 다운로드합니다.
2. 터미널(또는 명령 프롬프트)을 열고, 프로젝트 폴더로 이동합니다.
3. 필요한 파이썬 패키지를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
4. 스트림릿 앱을 실행합니다. (파이썬 파일 이름이 `app.py`인 경우)
   ```bash
   streamlit run app.py
   ```
5. 브라우저에서 자동으로 열리는 화면(`http://localhost:8501`)에서 `busan_subway.csv` 파일을 업로드하여 앱을 사용합니다.

## 📂 파일 설명
* `app.py`: 스트림릿 웹 앱을 실행하는 메인 파이썬 코드 파일입니다.
* `requirements.txt`: 프로젝트 실행에 필요한 파이썬 패키지 목록입니다.
* `busan_subway.csv`: 분석에 사용되는 부산 지하철 데이터 파일입니다. (업로드용)
